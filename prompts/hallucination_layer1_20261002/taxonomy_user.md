## Layer 1 — Substantive Legal（4 大类）

### L1.1 Authority Hallucination · 来源/权威幻觉

**适用面**：所有需要引用法律权威来源的题型。

| 子类 | 描述 | 典型例子 | 判定提示 |
| --- | --- | --- | --- |
| **L1.1.1 Source Fabrication**<br>来源编造 | 编造不存在的法条 / 司法解释 / 案号 / 会议纪要 / 官方文件 | "《民法典》第 1300 条规定…"（实际仅 1260 条） | ⚠ **必须挂外部法条库**核对，judge LLM 不可独立判 |
| **L1.1.2 Citation-Content Misapplication**<br>引用错配 | 来源真实存在，但与本案情境不适用；或来源描述与实际内容不符 | 引《合同法》（已废止）解决合同纠纷；"《民法典》第 1062 条规定夫妻共同债务"（实为共同财产） | 给 judge 提供原文 + 题目情境 |
| **L1.1.3 Temporal Invalidity**<br>时效失效 | 引已废止 / 未生效 / 修订前的法律 | 2021 年后的案情仍引《合同法》《担保法》而非《民法典》合同编 | 需法条生效/失效时间数据；注意模型时点 vs ground_truth 时点 |
| **L1.1.4 Hierarchy Error**<br>位阶错误 | 混淆法律位阶 / 地域效力 / 部门法效 | 用地方规章对抗上位法；把行政法规当作"法律" | LLM 体系知识可判 |
| **L1.1.5 Granularity Error**<br>粒度错位 | 条/款/项/目 定位错（条目本身存在） | 第 142 条第 1 款 → 写成第 2 款 | 给 judge 法条全文核对；与 L1.1.1 区分：这里**条目存在**，只是定位错 |

### L1.2 Doctrine Hallucination · 学理/构成要件幻觉

**适用面**：考察实体法概念、要件、例外、后果、学说立场的题。

| 子类 | 描述 | 典型例子 | 判定提示 |
| --- | --- | --- | --- |
| **L1.2.1 Conceptual Confusion**<br>概念混淆 | **把 A 整体识别成 B**（身份层错入，整段论述沿 B 的逻辑展开） | 表见代理 → 无权代理；担保 → 债务加入；重大误解 → 欺诈 | 看是否"走错概念分支"，与 L1.2.2 区分见下 |
| **L1.2.2 Element Misstatement**<br>要件描述错误 | 概念识别正确，但要件 / 成立条件 / 适用门槛说错某项 | 表见代理认对了，却说"必须有过错"（实际是"善意+合理信赖"） | 看 ground_truth 给的要件清单逐项核 |
| **L1.2.3 Exception Omission**<br>例外/抗辩遗漏 | 漏掉例外、抗辩、阻却事由、限制条件 | 谈合同效力没提"显失公平可撤销"；谈违约责任没提"不可抗力免责" | rubric 中明确"必须提及的例外清单" |
| **L1.2.4 Consequence Error**<br>法律后果错误 | 法律后果 / 责任形式 / 救济方式 / 处罚后果说错 | 应判返还原物却说赔偿损失；应认无效却说可撤销 | 给 ground_truth 即可 |
| **L1.2.5 Doctrinal Position Confusion**<br>学说立场混淆 | 通说与少数说混用；主客观主义、合同效力四态（成立/生效/无效/可撤销）等立场不一致 | 刑法因果判断主客观主义混用；同一论证中"未成立"和"无效"切换 | 看模型是否反复切换立场；法考通说优先 |
| **L1.2.6 Discretionary Judgement Error**<br>裁量/价值判断错 | 不确定法律概念错用（"情节较重"、"显失公平"、"足以推翻原判决"） | 刑法量刑情节认定边界判错；民法显失公平边界错 | 容许灰度；rubric 给参考裁量标准 |

> **L1.2.1 vs L1.2.2 判定规则**：先问"是否走错概念分支"——是 → L1.2.1；只是要件项写错 → L1.2.2。

### L1.3 Procedural-Law Hallucination · 程序幻觉

**适用面**：民诉 / 刑诉 / 行诉 / 仲裁等程序性题。

| 子类 | 描述 | 典型例子 | 判定提示 |
| --- | --- | --- | --- |
| **L1.3.1 Jurisdiction Error**<br>管辖错误 | 级别 / 地域 / 专属 / 协议管辖错 | 标的额超过基层管辖却判基层 | LLM 程序法知识可判 |
| **L1.3.2 Period Error**<br>期间/时效错误 | 诉讼时效、除斥期间、上诉期间、申请期间错 | 民事一般诉讼时效 3 年→说 2 年；民事上诉期 15 天→说 10 天 | 数字精度，rubric 易标 |
| **L1.3.3 Procedural-Step Error**<br>程序步骤错误 | 起诉、受理、答辩、举证、保全、执行的具体步骤错 | 答辩期被告说"30 天"（实际 15 天）；说"财产保全必须先起诉"（实际可诉前） | LLM 可判 |
| **L1.3.4 Procedural-Outcome Error**<br>程序后果错误 | 程序结论判断错——**驳回起诉 vs 驳回诉请**、撤诉、缺席判决 | 应"驳回起诉"（程序问题）却说"驳回诉请"（实体问题） | ⚠ 中国民诉高频判错点，必须单独标 |
| **L1.3.5 Appeal Error**<br>救济路径错误 | 二审、再审、抗诉、复议、执行异议等路径错 | 行政案件应复议前置却直接起诉 | LLM 可判 |

### L1.4 Application & Subsumption Hallucination · 事实涵摄幻觉

**适用面**：所有需要从案情提取事实并对应到法律规则的题。

| 子类 | 描述 | 典型例子 | 判定提示 |
| --- | --- | --- | --- |
| **L1.4.1 Fact Fabrication**<br>事实编造 | 编造题干没有的事实、金额、时间、主体、行为 | 题干无"协议离婚"，模型说"双方协议离婚" | 给原案情即可 |
| **L1.4.2 Fact Omission**<br>事实遗漏/错置 | 漏关键事实，或把非关键事实当成关键 | 漏看"被告系国家工作人员"导致漏判受贿罪 | ⚠ 需 rubric 给"必查事实点"清单，否则 judge 会同样漏 |
| **L1.4.3 Element-Fact Mismatch**<br>要件与事实错配 | 规则要件**正确**，但与本案事实**对应错** | 表见代理要件说对，却说"相对人不知情"满足"善意"（题干已说知情） | 与 L1.2.2 区分：L1.2.2 是要件本身错，L1.4.3 是要件正确但挂错事实 |
| **L1.4.4 Party Confusion**<br>当事人混淆 | 当事人身份 / 诉讼地位 / 权利义务主体混淆 | "甲方"和"乙方"反向适用；把代理人当本人 | 给原案情即可 |
